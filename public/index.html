Why Windows may warn you

The first time you run the file, Windows SmartScreen may say Windows protected your PC. Click More info, then Run anyway. That warning appears for any program that isn't signed with a paid code-signing certificate. The file itself is a few lines of text you can open in Notepad: it downloads the install script from this site and runs it.

Keeping it free

EasyInstall is free and has no ads. A code-signing certificate would make that warning go away, and donations are what pay for it. If EasyInstall saved you an afternoon, a coffee helps.
